## §1 공통 지침 (전 데스크 + PM)

### 1a. 🌐 소스 우선순위 [정훈 지침 2026-06-16 — 영구]

리서치 시 **국내 기사에 의존하지 말고 기관·증권사 자료와 외신을 폭넓게·유심히** 본다.

1. **증권사/IB sell-side 우선**: 목표주가·투자의견(Buy/Hold/Sell)·투자포인트·리스크·추정치를 인용. 국내(미래에셋·삼성·KB·NH·하나·한투·메리츠 등) + 글로벌(**Goldman·Morgan Stanley·JPMorgan·Citi·UBS·BofA·Barclays·Jefferies·Wells Fargo·Bernstein** 등).
2. **외신 적극 활용**: Bloomberg·Reuters·CNBC·FT·WSJ·Barron's·Seeking Alpha·TipRanks·Nikkei.
3. **하우스별 목표가 레인지 명시**: 최고/최저 하우스, **상향/하향 이력(누가·언제·얼마→얼마)**, 강세·신중 양쪽 하우스 논거.
4. **단일 출처 금지**: 복수 하우스·외신 교차검증, 충돌 시 "미확인" 표기. 채널·자막 수치는 기관 수치로 검증.

### 1b. 검증 규율

- 단일 출처 의심 수치는 항상 교차검증. 불확실하면 **"미확인"** 명시, 추측 금지.
- **[6/28] 미확인 최소화 의무**: [미확인] 태깅 전 추가 WebSearch 2~3회(다른 키워드·영문·기관 출처). 확인되면 [검증/정정] 승격, 라이브 수치는 범위 추정, 끝내 불가면 "N개 출처 시도" 명시.
- **시세는 `market_data.py` 결과를 그대로** 쓴다 — 임기응변 별도 재조회 금지(7/1 `.KS` 오티커 재발 사고의 원인).
- 미국 발표 일정은 **"美 현지일 + KST 환산" 병기**(6/22 데스크 간 날짜 충돌 사고 — 예: MU 실적 = 美 6/24 마감 후 = KST 6/25 새벽).

### 1c. 데스크(서브에이전트) 파일 표준 — "4계약" [7/4 채택, Anthropic]

agent 파일을 만들거나 고칠 때 아래 4요소가 전부 있는지 확인한다(하나라도 빠지면 드리프트):
**①목적(objective) ②출력 형식(return format) ③툴·소스 지침(이 플레이북 Read 포함) ④과업 경계**(예: "미장은 us-market-desk 소관 — 건드리지 않는다", "보고서 파일은 PM만 쓴다").

## §2 캘리브레이션 교훈 (self-review가 주간 갱신 — 최신: 2026-07-04, 표본 165콜)

전 데스크·PM이 별점·확신 표현을 다룰 때 반드시 기억할 것:

- **별점 ≠ 단기 상승확률 (2회 연속 실증)**: ⭐5 표현확신 85% vs 실제 상승 24%(갭 **−61%p**), ⭐4 68% vs 41%. **Brier 0.331 > 무정보 0.25 = ⭐4~5 과신 플래그 심화**(6/29 0.307). 별점 = 장기 퀄리티·확신이며, 단기는 수급·매크로가 지배한다. 보고서에서 별점을 단기 예측처럼 쓰지 말 것 — risk-desk가 이 수치로 제동 거는 게 공식 임무.
- **수급 레짐이 펀더를 지배할 수 있다 + 빗나감은 클러스터로 진단**: 서킷 2회(6/23·7/2) 레짐에서 ⭐5 GOOGL +4.0%·MSFT +4.4%는 맞고 MU −7.2%·AVGO −5.2%·LG전자 −5.4%가 깨짐(⭐5 5종 중 3종이 메모리). **[7/4 알파 컬럼 신설로 정밀화]**: 알파 기준으로도 ⭐5 역전 잔존(−3.22% vs ⭐3 +0.64%) — 순수 레짐 탓이 아니라 **메모리 테마의 벤치마크 대비 단기 언더퍼폼**이 실체. 빗나감 보고 시 펀더 vs 수급(레짐) vs 테마 클러스터를 알파로 구분해 서술.
- **매수존 심도는 해소(6/29 "너무 깊다" 철회)**: 7/4 진입률 46%(21/46, 6/29 24%) — 7/2 폭락이 존까지 도달. 이제 관건 = 존 도달 시 **실제 분할 집행**과 반등의 질.
- **경제사냥꾼 트랙레코드(누적 338주장 · 7/12 원인분석 = call_scorecard 참조)**: 검증 56%·정정 13%·미확인 31% — **판정가능분 기준 적중 82%**(미확인=판정불가이지 감점 아님). 정정의 태반 = 자동자막 STT 숫자 노이즈(~40%) + 10배 단위 과장(억↔조·$B 환산, ~30%)이지 **방향 오류 아님**(방향 오류는 초기 2건뿐). 방향성 채택·숫자 교차검증 유지, **10배 단위 수치는 최우선 의심**.
- **오미션도 채점한다 + 무행동 편향 균형 [7/4 미스무브 회고 신설]**: 커미션(별점 콜)뿐 아니라 안 산/안 판 결정도 후행회고(`missed_moves.py`·`hindsight_log.md`). 단 **`good_inaction`(관망·룰이 손실을 회피) 함께 계상** — 1회차서 상장 전 진입금지 룰이 SK하이닉스 −17% 회피·원익IPS 추격금지가 −17% 회피 = 룰 유효성 실증. 관망을 단기 급등 하나로 과벌 금지(결과론 함정).

## §4 유지 규약 — 지속 학습 루프 [7/4 신설, 일회성 아님]

1. **매 보고서**: PM 종합 후 "이번에 배운 것"이 있으면 §3 해당 데스크에 0~3줄 append(날짜 태그). 없으면 생략 — 억지로 채우지 않는다. **교훈은 구체·실행형으로**(다음에 무엇을 다르게 할지가 문장에 들어가야 함 — "조심하자" 류 일반론 금지. Reflexion 원칙, study_log 7/4 #7).

3. **정훈 지적**: 즉시 반영(영구교정과 동일 경로). master §7·CLAUDE.md와 중복되면 여기엔 **데스크 작업에 필요한 형태**로만 요약.
4. **외부 공부**(study_log 채택분): 채택 판정 난 방법론은 해당 §에 반영하고 출처를 남긴다.
