> **용도**: PM과 8개 데스크(서브에이전트)가 **작업 시작 전 Read하는 단일 정본**. 각 agent 파일엔 "자기 데스크 고유 룰"만 남기고, 전 데스크 공통 지침과 누적 교훈은 여기서 관리한다(6개 파일에 중복되던 소스지침을 단일화 — 수정도 여기 한 곳만).

## §1 공통 지침 (전 데스크 + PM)

### 1a. 🌐 소스 우선순위 [정훈 지침 2026-06-16 — 영구]

리서치 시 **국내 기사에 의존하지 말고 기관·증권사 자료와 외신을 폭넓게·유심히** 본다.

1. **증권사/IB sell-side 우선**: 목표주가·투자의견(Buy/Hold/Sell)·투자포인트·리스크·추정치를 인용. 국내(미래에셋·삼성·KB·NH·하나·한투·메리츠 등) + 글로벌(**Goldman·Morgan Stanley·JPMorgan·Citi·UBS·BofA·Barclays·Jefferies·Wells Fargo·Bernstein** 등).
2. **외신 적극 활용**: Bloomberg·Reuters·CNBC·FT·WSJ·Barron's·Seeking Alpha·TipRanks·Nikkei.
3. **하우스별 목표가 레인지 명시**: 최고/최저 하우스, **상향/하향 이력(누가·언제·얼마→얼마)**, 강세·신중 양쪽 하우스 논거.
4. **단일 출처 금지**: 복수 하우스·외신 교차검증, 충돌 시 "미확인" 표기. 채널·자막 수치는 기관 수치로 검증.

### 1b. 검증 규율

- 단일 출처 의심 수치는 항상 교차검증. 불확실하면 **"미확인"** 명시, 추측 금지.
- **[6/28] 미확인 최소화 의무**: [미확인] 태깅 전 추가 WebSearch 2~3회(다른 키워드·영문·기관 출처). 확인되면 [검증/정정] 승격, 라이브 수치는 범위 추정, 끝내 불가면 "N개 출처 시도" 명시.
- **시세는 `market_data.py` 결과를 그대로** 쓴다 — 임기응변 별도 재조회 금지(7/1 `.KS` 오티커 재발 사고의 원인).
- 미국 발표 일정은 **"美 현지일 + KST 환산" 병기**(6/22 데스크 간 날짜 충돌 사고 — 예: MU 실적 = 美 6/24 마감 후 = KST 6/25 새벽).

### 1c. 데스크(서브에이전트) 파일 표준 — "4계약" [7/4 채택, Anthropic]

agent 파일을 만들거나 고칠 때 아래 4요소가 전부 있는지 확인한다(하나라도 빠지면 드리프트):
**①목적(objective) ②출력 형식(return format) ③툴·소스 지침(이 플레이북 Read 포함) ④과업 경계**(예: "미장은 us-market-desk 소관 — 건드리지 않는다", "보고서 파일은 PM만 쓴다").

## §2 캘리브레이션 교훈 (self-review가 주간 갱신 — 최신: 2026-06-29 v34, 표본 112콜)

전 데스크·PM이 별점·확신 표현을 다룰 때 반드시 기억할 것:

- **별점 ≠ 단기 상승확률**: ⭐5 표현확신 85% vs 실제 상승 43%(갭 −42%p), ⭐4 68% vs 45%. **Brier 0.307 > 무정보 0.25 = ⭐4~5 과신 플래그.** 별점 = 장기 퀄리티·확신이며, 단기는 수급·매크로가 지배한다. 보고서에서 별점을 단기 예측처럼 쓰지 말 것.
- **수급 레짐이 펀더를 지배할 수 있다**: 6월 후반 외인 −8.3조 역대 매도 국면에서 ⭐5 대형 코어(삼성·MU·NVDA)가 가장 크게 맞음 — 펀더 무손상이어도 단기 방향은 어긋난다. 빗나감의 성격(펀더 vs 수급)을 구분해 보고.
- **매수존이 너무 깊다**: 폭락장에서도 매수존 도달 7/29(24%) — 상단을 현재가에 더 가깝게 잡는 안 검토(안 닿는 존은 없는 존).
- **경제사냥꾼 트랙레코드(누적 135편 기준 정확도 ~64%)**: 검증·근사 다수이나 **정정(수치오류) ~12%·미확인 다수** — 방향성 채택·숫자 교차검증 원칙 유지.

## §3 데스크별 누적 교훈 (PM·self-review가 append — 날짜 태그, 오래된 것은 통합)

### macro-desk (매크로)
- **한국은행은 점도표를 발표하지 않는다**(연준 전용) — 재발 금지 영구교정.

### research-feed (리서치 피드)
- 채널 **자막 수치 오류·과장 잦음**(누적 정정 ~12%) — 방향성 채택·숫자는 기관·외신 교차검증. 채널 단독 근거 매수 금지.
- [7/2] "웹 봇차단 → 로컬 대기" 서사 금지 — 실체는 버스트 레이트리밋, 페이싱·백오프·`--ids` 재시도로 해소. **제목만 로깅(추측 분석) 금지.**
- 외부 채널(지식인사이드 등)은 `fetch_youtube.py`(+`SSL_CERT_FILE=/root/.ccr/ca-bundle.crt`), 경제사냥꾼만 `hunter_latest.py`.

## §4 유지 규약 — 지속 학습 루프 [7/4 신설, 일회성 아님]

1. **매 보고서**: PM 종합 후 "이번에 배운 것"이 있으면 §3 해당 데스크에 0~3줄 append(날짜 태그). 없으면 생략 — 억지로 채우지 않는다.
2. **주간 self-review**: 캘리브레이션 결과로 §2 수치·플래그 갱신(수치 갱신은 자동, **채점기준 변경은 정훈 승인 후** — 기존 규약 유지).
3. **정훈 지적**: 즉시 반영(영구교정과 동일 경로). master §7·CLAUDE.md와 중복되면 여기엔 **데스크 작업에 필요한 형태**로만 요약.
4. **외부 공부**(study_log 채택분): 채택 판정 난 방법론은 해당 §에 반영하고 출처를 남긴다.
5. **분기 압축**: 오래된 교훈은 통합·일반화해 파일을 ~200줄 이내로 유지(비대해지면 데스크가 안 읽는다).
