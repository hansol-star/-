# 계좌·세금·레포 공개 범위 (2026-10-01)

> 발단 = 정훈 10/1 *"군인, 10월 28일 전역, 그 후 알바로 월 100만원 정도(미정). 연금저축·IRP 없음. ISA는 있는데 어떻게 써야 할지 모르겠다."*
> 조사 = 4개 에이전트(ISA·연금/청년 제도·레포 공개·사실 검증) · 핵심 주장 46건 중 38건 유지, 7건 확인 불가, 1건 갱신.
> **이 문서가 `tax_plan_2026-09-30.md` §1(연금저축 우선)과 §3(ISA)을 대체한다.** 결정 = d228·d229.

## 0. 결론

| 항목 | 판정 | 이유 |
|---|---|---|
| 연금저축·IRP | **지금은 안 한다** | 2026·2027년 낼 소득세가 0원이다(병 급여 비과세 + 알바 연 1,200만 수준). 세액공제는 낸 세금을 돌려받는 것이라 0원에서 돌려받을 게 없다 |
| 청년미래적금 | **10/7~10/16 신청** | 정부기여 6% — 월 50만 납입이면 연 36만원 = 시스템 구독비. 소득세와 무관하게 붙는다 |
| ISA | **유지 · 해지 금지 · 지금은 넣을 것 없음** | 현 규모에선 효과가 연 1만원 안팎. VOO는 직접 보유가 유리(양도차익 연 250만 공제 → 세금 0원) |
| 근로장려금 | **조건부** | 가구 재산 2.4억 미만이어야 한다 — 부모와 같은 주소면 합산돼 0원일 수 있다 |
| 레포 | **이전 후 비공개** | private 전환만 하면 앱이 죽는다. Cloudflare로 옮긴 뒤 전환 |

9/30 문서의 *"세금이 가장 확실한 회수 경로 — 연금저축 연 218만~273만이면 시스템 비용 회수"*는 **근로소득세를 내는 사람 기준 계산**이었고 정훈 소득에선 성립하지 않는다.

## 1. 청년미래적금 — 기한이 있는 유일한 항목

- **2차 신청 2026-10-07 ~ 10-16**(7·8일 출생연도 홀짝제, 12~16일 자유) · 심사 10/19~11/13 · 계좌개설 11/16~27 — 금융위 [검증]
- 3년 만기 · 월 1천원~50만원 자유납입 · 정부기여 일반형 6% · 이자 비과세 · 기본금리 5% + 우대
- **군 장병도 2025년 병 급여로 소득요건 충족 가능** — 정책브리핑 [검증]. 병역기간은 연령 계산에서 빠진다
- 월 50만 → 기여금 연 360,000원 / 월 30만 → 216,000원 / 월 20만 → 144,000원
- ⚠️ [미확인] 가구 중위소득 200% 심사 통과 여부(부모 소득 포함) · 일반 중도해지 시 기여금 처리 약관(가입 은행 상품설명서로 확인)
- ⚠️ 3년 묶인다. 신청과 납입액은 별개 — **신청은 지금, 납입액은 전역 후 소득을 보고** 정한다. 다음 창은 2027년
- ⚠️ 재원 충돌: 월 50만을 여기 넣으면 룰9 VOO 월 적립과 같은 돈을 놓고 다툰다. 확정 6% + 금리 vs 주식 기대수익 — 소득이 정해지면 배분을 다시 정한다

## 2. ISA 사용법

현행: 연 2,000만 · 총 1억 · 비과세 200만(서민형 400만) · 초과분 9.9% · 의무 3년. *(연 4,000만/비과세 500만 확대는 미시행 · '생산적금융 ISA'는 2027년 정부안 — 국회 통과 전)*

1. **먼저 정체를 확인한다** — 어카운트인포(payinfo.or.kr)에서 금융사 → 그 앱에서 유형(중개형/신탁형/일임형)·서민형 여부·가입일. 토스증권은 2026-05 기준 ISA가 없었다
2. **해지하지 않는다** — 가입일부터 3년 시계가 돌고 있다. 그 시계가 지금 이 계좌의 가치다
3. **VOO를 팔아 옮기지 않는다** — ISA에선 VOO(해외 상장)를 못 사고, 직접 보유는 연 실현차익 250만까지 세금 0원이다. 올해 실현 +434,780원 → 공제 잔여 약 207만
4. **ISA가 값을 하는 경우**: ⓐ국내 배당주·국내상장 ETF(일반계좌는 배당 15.4%) ⓑ국내상장 해외지수 ETF를 살 일이 생기면 반드시 ISA 안에서 ⓒ해외주식이 커져 한 해 실현차익이 250만을 넘기 시작할 때(대략 해외 보유 2,500만원 이상) 신규 적립분을 ISA의 국내상장 S&P500 ETF로
5. 신탁형·일임형이면 **중개형으로 이전**(가입기간 승계) — 주식·ETF를 직접 못 사거나 일임 수수료가 나간다
6. 서민형 전환은 비용 0이지만 급하지 않다(일반형 200만 한도도 못 채운다). 전환 가능 시점은 금융사마다 달라 [미확인]
7. ⚠️ 룰6(국내주 > 22%면 국내 매수 0원)이 걸려 있는 지금은 ISA에 넣을 국내 자산 자체가 없다

## 3. 그 밖의 확정·조건부 수익

- **장병내일준비적금**: 가입돼 있으면 만기 = 전역일(10/28), 매칭지원금은 최대 3개월 뒤 별도 입금. 신규 가입은 이제 불가. **가입 여부·납입액 미확인**
- **근로장려금**: 산식상 2026 귀속 약 82만(2027-05 신청) · 2027 귀속 약 127만. 단 **가구 재산 2.4억 미만**(1.7억 이상은 절반) — 부모와 주민등록이 같으면 부모 재산이 합산된다. 홈택스 모의계산으로 확인
- **알바 소득 형태**: 근로소득·일용근로면 소득세 0원. 3.3% 사업소득이면 원천징수분을 다음 해 5월 종합소득세 신고로 돌려받는다(신고 안 하면 못 받는다)

## 4. 레포 비공개 전환 (d229)

**왜 그냥 못 바꾸나**: GitHub Free는 public 레포만 Pages를 준다 → private으로 바꾸는 순간 폰 앱이 내려간다. 5~10분 재배포 Actions가 월 2,700~4,100분이라 private 무료 한도(2,000분)도 넘는다. GitHub Pro($4)는 사이트가 여전히 전 세계 공개라 해법이 아니다.

**이미 나간 것은 못 거둔다**: 포크·스타 0, Wayback 스냅샷 없음 = 확인된 제3자 사본은 없다. 그러나 "아무도 안 가져갔다"는 증명할 수 없다. 커밋 작성자 메타데이터에 **개인 Gmail 주소가 134개 커밋**에 남아 있다(`git log --format=%ae` 직접 확인 [검증]) — 과거분은 히스토리 재작성 없이는 못 지우고, 이미 복제된 사본엔 손댈 수 없다. 앞으로의 커밋은 GitHub noreply 주소로 바꾸면 막힌다(정훈 git 설정).

**구조(0원)**: Cloudflare Worker 1개 = 정적 자산(app/) + cron이 시세를 받아 KV에 기록 + `/live.json` 응답, 앞단에 Cloudflare Access(본인 이메일 OTP).

| 순서 | 누가 | 무엇 |
|---|---|---|
| 1 | PM | `worker/` 작성(wrangler 설정·시세 수집 JS 포팅·`/live.json`) · 앱에 noindex·재로그인 유도 |
| 2 | **정훈** | Cloudflare 계정 + Zero Trust 조직 생성(무료 플랜) · API 토큰을 GitHub Secrets에 등록 |
| 3 | **정훈** | 빈 Worker 배포 → **Access 먼저 켠 뒤** 데이터 자산 배포(순서 바뀌면 잠깐 공개된다) |
| 4 | **정훈** | 아이폰 실기기 시험 — 로그인 → 홈 화면 추가 → 장중 갱신 → 완전 종료 후 재실행 |
| 5 | PM | deploy-app.yml을 push 시 배포로 교체(스케줄 삭제) · live_quotes·문서 URL 정리 |
| 6 | **정훈** | Claude GitHub App을 레포에 설치(클라우드 루틴 C2/C3용 — 공개 상태에서 미리) |
| 7 | **정훈** | Settings → visibility private · 직후 루틴 1회·푸시 1회 확인 |

**새 앱이 폰에서 검증되기 전엔 옛 Pages를 내리지 않는다.**

⚠️ [미확인] 전제 3개 — 4단계에서 막히면 멈춘다: ①Zero Trust 무료 가입에 결제수단이 필요한지 ②iOS 홈화면 PWA가 Access 로그인 뒤에서 끝까지 도는지 ③Cloudflare IP에서 야후·네이버 시세가 차단 없이 오는지(10분짜리 시험 Worker로 실측).
보조안 = 로컬 PC + Tailscale(코드 변경 최소 · PC가 꺼지면 앱이 죽는다).
