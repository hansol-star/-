**교정 제안 (자동변경 ❌ · 정훈 확인 후):**
1. **STAR_PROB 매핑 유지 + 이행 완료 확인**: 6/29 제안("별점≠단기 상승확률 명시")은 7/4 `desk_playbook.md` §2 명문화 + risk-desk '캘리브레이션 브레이크' 공식 임무로 **구조화 완료**. 다음 캘리브레이션에서 브레이크 작동 효과 추적.
2. **벤치마크 알파 컬럼 — 정훈 승인·당일 구현 완료 (7/4)**: `score_calls.py`에 콜별 벤치마크(국내 ^KS11/미국 VOO) 대비 알파 + 알파 Brier + 알파 역전 플래그 추가. **첫 실행 결과가 위 해석을 일부 교정**: ⭐5 알파 **−3.22%** < ⭐3 +0.64%, 알파 Brier 0.337 ≈ 절대 0.331 → **역전은 레짐만의 소산이 아님** — ⭐5 메모리 콜(MU·AVGO 등)이 벤치마크 대비로도 밑돌았다. 다만 ⭐4~5 내 GOOGL·MSFT·META는 벤치마크 상회 → 결론 정밀화: "채점 전반의 실패"도 "순수 레짐"도 아닌 **메모리 테마 논지의 단기 언더퍼폼**이 ⭐5 버킷을 끌어내림. §10-2 마진 추세 판정(정점 감시)이 바로 이 논지의 감시 장치 — 다음 캘리브레이션에서 메모리 vs 비메모리 알파 분리 추적.
3. 매수존 상향 제안(6/29 #2)은 **철회** — 46% 진입으로 해소. 대신 "닿고 반등" 질 측정을 score_calls 후속 과제로.
4. 메모리 집중: 별점 채점기준 문제가 아니라 **포트 구성 리스크** — §10-2 마진 추세 판정(가속=홀딩) 유지하되, risk-desk 집중도 경보를 매 보고서 유지.
