## 0. 왜 '네이버'인가 — Yahoo가 못 주는 한국 축

기존 `chart_read.py`는 **Yahoo OHLC**만 읽어, 한국 차트 판독의 절반인 **수급(투자자별 매매동향)**과
**외국인 지분율**이 빠져 있었다. Yahoo엔 한국 수급이 아예 없다. 네이버 무키 API 3종이 이를 채운다
(데이터센터 IP에서 200 정상):

| 소스 | 엔드포인트 | 주는 것 |
|---|---|---|
| **차트 봉** | `api.stock.naver.com/chart/domestic/item/{code}/{day\|week}` | OHLCV + **봉별 외국인지분율(frr)** · 6.5년 심층(삼성 1,608봉) |
| **투자자 수급** | `m.stock.naver.com/api/stock/{code}/trend` | 최근 ~60거래일 외인/기관/개인 순매수 **수량** + 외인보유율 |
| **재무·컨센** | `m.stock.naver.com/api/stock/{code}/finance/annual` + `/integration` | 매출·영업이익·EPS·PER 3개년 실적 + **2026(E) 컨센** · 목표주가·투자의견·추정PER/EPS |

⚠️ 데이터 정합성(7/22 실측): chart/day 마지막 종가 = 네이버 라이브 `basic` 종가와 **전 종목 정확히 일치**
(삼성 260,500·LG 182,700·NAVER 196,900·두산로보 67,600·현대차 418,000·하이닉스 1,830,000). 신뢰 가능.

## 1. 한국식 차트 판독 3층 구조 (naver_chart.py)

한국 대형주 차트는 **가격 기술구조 + 수급 + 밸류에이션** 3층을 겹쳐 읽는다. 각 층의 시간축이 다르다.

### ① 가격 층 (타이밍) — `chart_read` 엔진 재사용
네이버 봉을 `chart_read.read(ohlc=…)`에 **주입**해 기존 13신호 컨플루언스 엔진을 그대로 돌린다
(엔진 단일화 — 소스 무관). 52주 고저·MA200 정합 위해 일봉은 최근 252봉만 주입, frr 심층은 별도 사용.
RS 벤치는 코스피(`.KS` 티커로 넘겨 자동 해석).

### ② 수급 층 (전술·구조 혼합) — 핵심 신설
- **외국인 지분율 추세**(느린·구조): Δ5/20/60봉 + 1년 %ile + 방향. 지분율(보유/발행)은 순매수 '수량'의
  심층 프록시 — 억원 net보다 float·가격 착시가 적다.
- **순매수 수량**(빠른·전술): 외인 연속일(streak)·5/20일 누적·기관 동행/역행·개인 대치.
- **★크기 정규화(필수)**: 20일 누적 순매수를 **평균거래량 대비 days-of-volume**으로 환산, |0.5일| 미만은
  중립 처리. 부호만 보면 하루 거래량 2%짜리 미미한 순매수를 '매집'으로 과대평가한다(LG전자 +3.7만주 =
  0.06일 → 중립이 맞다). → 유의미 매집/분산만 라벨.
- **소진율 착시 자동 표기**: 20일 net은 매도인데 지분율은 상승 같은 상충(하이닉스 7/22 실측)을 두 하위신호로
  분리 표기해 순매도 억원≠지분율 방향을 드러낸다.

### ③ 가치 층 (구조) — `naver_value.py`
§2 참조. 영업이익 추세 + 선반영 판단.

### 종합(synthesis) 규약
구조(가치)와 국면(가격+수급)을 **분리**해 한 줄 판단. 과신 금지·상충 병기. 예(삼성 7/22):
"구조 저평가(성장 미반영) · 국면 정렬 약세 → 구조는 싸나 국면은 아직 약함, 분할·인내(추격 금지)".
= 안전핀·"공포에 사라 분할" 철학과 정합.

## 2. 밸류에이션 '선반영' 판단 (naver_value.py)

정훈 질문 "앞으로의 가치가 반영이 다 된 상태인지"의 정량화. 네이버가 **2026(E) 컨센 실적**을 주므로
트레일링 vs 포워드를 직접 비교한다.

**입력**: 영업이익 3개년+2026E·영업이익률(마진 방향)·EPS 방향·트레일링/포워드 PER·컨센 기대성장(추정EPS/실적EPS−1)·
목표가 상단·PEG류.

**판정 로직(오판 방지 장치 포함)**:
- **미반영 여지(+2)** = **신고 실적**(2026E 영업이익 > 1.2×과거 피크) + 강한 성장(≥30%) + **마진 가속**.
  → 순환회복(바닥실적 PER 착시)과 구분. (삼성·하이닉스: 2026E OP가 과거 8.8×/5.8×, 마진 52%/77%.)
- **선반영·고평가 경계(−2)** = EPS 감소 or (마진 둔화+저성장) + 포워드PER≥12. (NAVER: EPS −3.2%·포워드 16.4×.)
- **밸류트랩 경계(−1)** = 저PER(<8)인데 실적·마진 하락(싼 데는 이유).
- **부분 반영(순환 회복·+1)** = 포워드≪트레일링·성장 있으나 신고 실적 아님. (LG전자: 2026E OP가 2023 피크 겨우 +16%.)
- **내러티브(0)** = 적자·PER 무의미(두산로보 — 실적 아닌 스토리에 프라이싱).

**★냉정 경계 2종(항상 병기)**:
1. **컨센 공격성 플래그**: 기대성장 >100% or 2026E 마진이 최근의 2배↑ → 포워드 저PER은 **추정 실현 조건부**.
   리스크는 배수가 아니라 추정치(삼성 OP +779%E·하이닉스 +478%E는 극단적 컨센).
2. **목표가 stale 의심**: 목표 상단 >50%인데 EPS 감소·마진 둔화 → 크래시 후 애널 목표 미갱신 프록시
   (7/22 현대차·NAVER·두산로보에서 발화). 큰 상단을 강세 근거로 오용 금지.

## 3. ★수급 신호 forward 엣지 백테스트 (flow_edge.py · 냉정한 검증)

signal_score.py가 **순수 가격신호 엣지≈0**(Stage4 회피·RSI 역발상만 유효)을 29년으로 실증했다.
같은 정직 기준으로 **한국 특유 수급 = Δ외국인지분율**의 forward 예측력을 측정(룩어헤드 차단: 신호는 t까지
정보만, 진입 t종가→성과 t+H, 엣지 = 신호평균−그 종목 baseline). 표본 = 국내 10종목·~16,000 종목일.

| 신호(pooled·표본가중) | 5일 엣지 | 20일 엣지 | 해석 |
|---|---|---|---|
| 완만 지분율↑(Δ20) | +0.12%p | **−0.56%p** | 매집 추격 = 20일 언더퍼폼 |
| **강한** 지분율↑(Δ20 상위20%) | +0.00%p | **−0.75%p** | 강한 매집일수록 더 나쁨(추격 금지) |
| 강한 지분율↑(Δ60) | −0.08%p | −0.47%p | 지속 매집 추격도 엣지 없음 |
| 강한 지분율↓(Δ20 하위20%) | −0.24%p | +0.03%p | 중립 |
| **강한 지분율↓(Δ60 하위20%)** | +0.05%p | **+1.36%p · 승률 57.1%** | ★유일한 견고 양(+)엣지 = 역발상 |

**정직한 결론**:
1. **외국인 '따라매수'는 forward 알파가 아니다** — 지분율↑ 추격은 20일 **음(−)엣지**(강할수록 −0.75%p).
   "외인 순매수일 코스피 89.7% 상승"은 **같은 날 동행상관**일 뿐 tradeable 선행신호가 아님. 학술(외국인
   추종수익률 < 코스피)과 일치. 수급 신호도 가격 신호처럼 **상태 서술 렌즈지 방향 베팅 근거가 아님**.
2. **유일한 견고 양(+)엣지는 역발상**: 외인이 **60일간 대량 이탈한 뒤**(하위 20%)엔 이후 20일이 baseline
   대비 **+1.36%p·승률 57%**. = signal_score의 "RSI 침체를 매도근거로 쓰지 말라(역신호)"를 **한국 수급 축에서
   재확인**. "공포에 사라 분할"의 하드넘버 근거(단, 드로다운-회복 레짐 의존 → '워시아웃 매수'로 한정).
3. 종목별 부호 비일관(LG전자 교과서형 ↑+3.6/↓−3.6 vs 두산로보·SK이노 역전) → **범용 규칙 없음**.

**운용 반영**: naver_chart의 수급 층은 **'매집/분산 국면 서술'로만** 쓰고 forward 매수/매도 트리거로 승격 금지.
행동 규칙으로 채택 가능한 것 = ①강한 외인 매집 뒤 추격 회피 ②장기(60일) 대량 외인이탈 워시아웃은 분할매수 후보(안전핀 하 게이트 준수). R3 주간 캘리브레이션이 이 표를 누적 갱신.
