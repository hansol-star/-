## 1. 장기 마진이 드러낸 것 — 5년으로는 안 보이던 3가지

### ⓐ 메모리는 아직 사이클 정점이 아니다 (강세 근거)
```
삼성전자 영업마진   2018: 24.2%  …  2023: 2.5%(역대 최저)  2024: 10.9%  2025: 13.1%
MU 영업마진        2018: 49.3%  …  2023: -37.0%          2024: 5.2%   2025: 26.1%
```
현재 삼성 13.1%는 **2018년 고점의 54%**, MU 26.1%는 **2018년 고점의 53%** 수준이다.
메모리 슈퍼사이클이라 불리는 지금이 **직전 사이클 정점의 절반**에 있다.
⇒ 8/30 MU 재검토에서 *"사이클 정점 위험"* 을 경계했는데, **장기로 보면 정점은 아직 멀다.**
⚠️ 단 이건 "더 오른다"가 아니라 **"마진만으로는 정점 신호가 없다"** 까지다. 같은 날 확인한
   *마진은 동행·후행이고 주가는 선행*(§10-2)이 여전히 위에 있다.

### ⓑ LG전자 마진 악화는 3년이 아니라 4년째다
```
2021: 5.2  2022: 4.3  2023: 4.2  2024: 3.9  2025: 2.8      ← 4년 연속 하락
11년 레인지 2.1(2015) ~ 5.2(2021) · 현재 2.8 = 역대 2번째 최저
```
정본 판정(`tranche_rules --rule2`)은 **1/3 = 정상**이다(FCF·순부채 미충족). 룰 자체는 유지한다.
그러나 **⭐4·스코어 74**가 4년 연속 마진 하락·역대 2번째 최저와 정합적인지는 별개 질문이다.
⇒ **§5 액션 ①**로 이월.

### ⓒ 두산로보틱스는 악화가 가속 중이다
```
영업마진  2023: -36.1%  2024: -88.0%  2025: -180.3%
```
매출 대비 영업손실이 **1.8배**다. ⭐2·스코어 41이 이 숫자를 이미 반영하고 있으나,
**비중 1.1%(35,800원)** 라 트림 실익이 크지 않다는 점도 같이 봐야 한다(8/28 오더 미체결 만료).

## 4. 폐기한 분석 — 역사적 PER 백분위

새 데이터(OHLCV + 재무 EPS)를 결합해 *"현재 밸류가 역사적으로 어디인가"* 를 계산했으나
**무효로 판정하고 폐기**한다.
- **원인**: Yahoo 종가는 **분할 조정**되고 재무 EPS는 **당시 기준(미조정)** 이다. 둘을 나누면
  NVDA 최저 PER **0.4**, AAPL **0.5** 같은 불가능한 값이 나온다(NVDA 10:1·AAPL 4:1 분할).
- **2차 원인**: 후행 EPS의 시차. MU는 FY2025 EPS $7.59 기준 PER 122.9로 계산되지만
  FQ4 가이던스(분기 EPS $30.73) 연환산으로는 **약 7.8**이다. 사이클 종목에서 후행 PER은 무의미.
- ⇒ 이 축을 쓰려면 **분할 조정된 EPS 시계열**(`split_guard.py` 활용)과 **선행 EPS**가 필요하다.
  **미해결 과제로 등록.**
- 📌 **교훈**: 새 데이터를 결합할 땐 **조정 기준(분할·통화·회계연도)이 서로 맞는지 먼저 확인**한다.
  데이터가 많아진 것과 결합이 타당한 것은 별개다.

## 5. 액션 — 승인 필요

**① LG전자 별점 재검토 (⭐4/74)** ← 이번 검토의 최대 발견
4년 연속 마진 하락 + 11년 중 2번째 최저(2.8%)인데 ⭐4다. 다만 반대 근거도 분명하다 —
원가 대비 **+29.8%**로 보유 중 최고 수익률이고, 데스크 기간 코스피 대비 **+2.90%p로 선방**했으며,
룰2 정본 판정은 **정상(1/3)** 이다. **별점 변경은 룰 영역이라 정훈 판단.**

**② NVDA 마진 첫 하락 감시 (62.4 → 60.4)**
비중 **22.9%로 최대**이고 위험 기여 19.8%다. 아직 역대 최고권이라 액션은 없으나,
**2분기 연속 하락 시 §10-2 판정을 중립으로 내린다**를 트리거로 걸어둘 것을 제안한다.

**③ 두산로보 트림 오더 재등록** (8/28 미체결 만료, ⭐2 = 결정 강제 대상)
마진 -180.3%로 악화 가속. 단 비중 1.1%(35,800원)라 실익은 작다.
`check_low_star_action`이 이미 WARN을 내고 있다 — **트림 오더 또는 기한부 홀드 중 하나**를 정해야 한다.

**④ 유지 확인** — 삼성·MU(메모리 정점 아직 아님)·MSFT·AAPL·GOOGL은 장기 마진이 판단을 지지한다.
