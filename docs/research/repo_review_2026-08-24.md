**게시물 주장 검증** — *"전부 무료 오픈소스"* = **[정정]**. VectorBT는 Commons Clause(OSI 오픈소스 아님·상업판매 제한),
Backtrader·Freqtrade는 GPL, Nautilus는 LGPL로 **전염성 라이선스**다. 10번은 3개월 전 죽은 리포이고,
*"백테스팅 표준"*(4번)은 3년 4개월 정체된 **과거형**이다. 스타 수 자체는 9/10이 ±0.3k 내로 정확했다.

**왜 8개가 한꺼번에 기각되나** — 목록의 성격이 우리와 다르다. 10개 중 6개(1·2·5·7·9·10)가 **주문 집행기**다.
우리는 토스 **조회 전용·주문 API 절대 금지**가 영구 룰이고, 이건 외부 지지도 있다(7/26 업계 인사: *"리스크 때문에 주문은 안 맡긴다"*).
3개(1·2·5)는 **크립토 전용**이라 자산군이 아예 다르다. 즉 이 목록은 *봇을 만드는 사람*의 도구이고,
우리는 *판단을 만드는 리서치센터*다 — 겹치는 지점이 구조적으로 작다.

**라이선스 실무 주의**: 우리 레포엔 `LICENSE` 파일이 없다(사유 레포). GPL-3.0(Backtrader)·LGPL(Nautilus) 코드를
복사해 넣으면 전염 문제가 생긴다. 8/23 gs-quant 이식이 안전했던 건 그쪽이 **Apache-2.0**이었기 때문이다.
⇒ 외부 코드는 **라이선스를 먼저 보고**, 허용적(MIT/Apache)이 아니면 **수식·정의만 재구현**한다.

## 2. 8번은 이미 우리 것 — 소스를 열어 확인한 것

## 3. 검토가 드러낸 우리 구멍 2개

### 구멍 1 — 손익비·기대값을 재는 스크립트가 83개 중 0개였다 ✅ **[이 세션에서 수정]**

VectorBT·Backtrader가 기본으로 내는 지표(Sharpe·MDD·손익비)를 우리는 거의 안 잰다. 실측:

| 지표 | 우리 커버리지 |
|---|---|
| 승률·중앙값 | 검증기 10종 대부분 |
| Sharpe·CAGR | **`sizing_backtest.py` 1곳뿐** |
| MDD | 5곳에 각자 재구현 |
| **손익비·기대값** | **0곳** |

그런데 **8/23 체결 원장이 실측한 우리 실제 실패 유형이 정확히 손익비다**:
미국주 40건 **승률 72.5%인데 손익비 0.81**(평균이익 +14.9% vs 평균손실 −18.4%) = *자주 이기지만 작게 이기고 크게 진다*(처분효과).
**승률만 보면 "72%면 잘하는 중"으로 읽혀 이 병이 안 보인다.** 우리는 우리 병을 재는 자를 안 갖고 있었다.

게다가 그 숫자는 8/23에 **손으로 계산해 CLAUDE.md 산문에만** 적혀 있었다 — 산문에 있는 지표는 다음 세션에 갱신되지 않는다
(8/2 *"오더북에 들어간 것만 집행된다"* 의 지표판).

**수정**: `trades.py`에 `_payoff()` 신설 — 손익비·기대값·평균이익/손실을 **era × 통화별**로 자동 산출.
통화를 갈라야 하는 이유는 손익비가 **미국주 0.81 vs 국내주 3.05로 정반대**라 합치면(1.13) 병이 사라지기 때문이다.
산문의 숫자가 원장에서 그대로 재현되는 것을 확인했다. **측정 전용 — 어떤 룰도 바꾸지 않는다.**

### 구멍 2 — 룩어헤드를 '주장'하는 파일 5개, '검사'하는 장치 0개 📋 **[제안·미실행]**

`signal_score.py`·`sizing_backtest.py`·`flow_edge.py`·`star_validate.py`·`snapshot_state_backfill.py`가
*"룩어헤드 없음"·"미래참조 없음"* 을 **주석으로 주장**한다. `selfcheck.py`·`validate_report.py`·`wiring_audit.py`
어디에도 이를 검사하는 장치가 **없다**(grep 0건).

TradingAgents는 **같은 자리에서 실제로 넘어졌다** — 이슈 #1115: *"payload가 JSON 문자열이라
fundamentals look-ahead 필터가 한 번도 실행되지 않았다."* 만들어둔 가드가 실제로는 안 돌던 버그로,
**우리 8/22 교훈(*"메타 성공 ≠ 생존"*)·8/23 교훈(*"초록불은 탐지기가 그 형태를 안 본다는 뜻일 수 있다"*)과 같은 클래스**다.
그들은 이를 **회귀 테스트 파일로 고정**했다(`test_news_lookahead.py`·`test_alpha_vantage_hardening.py`·`test_fred.py::test_window_is_lookahead_safe`).

우리 대비: **코드 회귀 테스트 0개**(`ratchet_test.py`·`ma_test.py`는 이름만 test인 백테스트 스크립트다).
런타임 가드 28개는 강하지만 **층위가 다르다** — 가드는 *데이터·보고서 내용*을 보고, 테스트는 *코드 로직*을 본다.
우리는 8/22·8/23에 *"음성 테스트로 검증한다"*를 교훈으로 세웠지만 **절차로만 했고 파일로 고정하지 않았다.**

**제안(정훈 판단 필요 — 규모가 있음)**: 백테스트·검증 계열의 룩어헤드 불변식을 회귀 테스트로 고정.
가장 작은 시작 = 미래 데이터를 섞은 입력을 넣고 결과가 안 변하는지 보는 음성 테스트 3~4개.
