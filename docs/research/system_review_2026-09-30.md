# 시스템 객관 평가 + 외부 리서치 (2026-09-30)

> 정훈 지시: *"우리 시스템 객관적으로 평가해보고… 최대한 다양한 자료 보면서 공부해보고 추가하거나 바꿀 시스템 있으면 보고"* + *"LLM 로컬 시스템이 좋다 하면 말해. 나중에 MAC MINI 살거야"*.
> 기준선 = 상업용 최상급·학계 최신 결과(7/20 톤 지침). 잘한 건 짧게, 부족분 먼저.

## 2. 외부 근거 — 학계·업계가 말하는 것

1. **LLM 트레이딩 에이전트는 정직하게 재면 buy-and-hold를 못 이긴다.** 20년·100+종목 백테스트에서 보고된 LLM 우위가 사라짐(arXiv 2505.07078) · TradingAgents 자체도 비용 반영 시 Sharpe 0.43→0.22, 5종목 중 4종목에서 B&H 열위 · 164편 리뷰 동일 결론 · Look-Ahead-Bench: 학습기간 안에서만 알파(기억)였다.
2. **실돈 LLM 에이전트 6개월 기록(arXiv 2609.05663, 3,505 볼트·750만 호출)**: ①행동을 정하는 건 전략 문장이 아니라 **운영층(제약·화면·주문 경로)** ②사이징이 **변동성 무시**(모든 변동성 구간에서 레버리지 동일) ③도달한 이익을 못 챙김 ④방향성 엣지 **없음**, 프런티어 모델 간 판단 품질 **통계적으로 구분 불가**. 처방은 "기계적이고 싼 것": 브래킷, 변동성 비례 사이징, 의사결정 출처 원장.
3. **개인투자자 문헌(Barber·Odean)**: 많이 거래할수록 수익이 낮고, 손실의 주원인은 **처분효과(이긴 종목 매도)**. 우리 -2.83%p의 구성(매도 -235,631원)과 정확히 같은 모양이다.
4. **오픈소스 동향(이번 주)**: TradingAgents v0.5.x(★109k) = 시점 무결성·**보고서에 생성 조건(모델·데이터 시각) 기록**·파싱 불가 판정을 Hold가 아니라 REVIEW로 · ai-hedge-fund(★64k) = 백테스트에서 **종목명·날짜를 가린(blind) 프롬프트**를 기본값으로. 둘 다 "LLM이 기억으로 맞히는 것"을 막는 쪽으로 가고 있다.
5. **재무 정확도**: 프런티어 모델도 Finance Agent v2 약 50%, 5단계 이상 계산에서 35% 미만. → 숫자는 코드가, 판단 틀은 룰이 잡아야 한다(우리 설계 방향과 일치).
6. **리밸런싱(Vanguard)**: 연 1회 점검 + 5% 이탈 밴드가 위험·비용 균형점. 잦은 조정은 비용만 늘린다.

## 3. 잘한 것 (짧게)

룰을 코드로 강제(`tranche_rules`·`validate_report`·가드 자가검증), 룰 변경의 3단 검정 절차(8/5)와 대조군 원칙(9/22), 시점 무결성 가드, 결정 원장, 주문 API 차단. **외부가 이제 막 도입하는 것들(시점 무결성·결정 원장·blind 검정)을 우리는 이미 갖고 있다.** 벤치마크 대비 성과 측정기(`performance.py`)가 있다는 것 자체가 대부분의 개인 시스템보다 앞선다.

## 4. 부족한 것 — 우선순위순

1. **매매가 가치를 빼고 있다.** 시스템의 가치는 분석이 아니라 제약(룰)에서 나온다는 외부 근거와 우리 실측이 같은 말을 한다. 그런데 운영의 무게는 여전히 매일 14~27종목 별점·산문에 있다.
2. **규모 대비 과잉 복잡도.** 약 810만원 포트에 37,600줄. 결함이 매일 새로 나오고(오늘만 5건), 무인 루틴이 자력으로 못 돈다. 유지비(토큰·시간)가 알파보다 크다.
3. **사이징이 변동성을 모른다.** 단일종목 상한 25%는 비중 기준. NVDA는 비중 최대이면서 변동성 최대, 삼성은 비중 15%에 위험 약 40%. 외부 논문의 ②와 같은 결함.
4. **가동 인프라가 PC 전원에 묶여 있다.** 예약 알림·루틴이 "PC 켜짐 + 앱 열림"에 의존.
5. **세금·계좌 구조가 시스템 밖이다.** 해외주식 양도세(연 250만원 공제·22%) 추적, 연말 손익통산, 연금저축·IRP(세액공제) 같은 **확정 수익**이 한 줄도 없다.

## 6. 맥미니·로컬 LLM — 결론

**맥미니는 사라. 단 이유는 로컬 LLM이 아니라 "항상 켜진 서버"다.**

- **핵심 이득 = 가동률.** 오늘 R1은 PC가 꺼져 109분 늦었고, 실적 알림 11개는 전부 "PC·앱 켜짐"이 전제다. 맥미니는 대기전력 수 W로 24시간 켜 둘 수 있다. 토스 API는 **IP 허용목록**이라 같은 집 회선이면 그대로 된다(회선 바뀌면 재등록).
- **로컬 LLM은 보조로만.** 쓸 곳 = 대량·저위험 작업: 유튜브 자막 요약(`hunter_digest`), 태깅·분류, 의미검색 임베딩. 이걸 로컬로 빼면 **구독 토큰 한도**(R2를 죽인 원인)를 판단 작업에 몰아줄 수 있다.
- **판단은 로컬로 넘기지 마라.** 프런티어 모델도 재무 과제 정답률 약 50%다. 로컬 30B급은 그보다 낮다. 별점·룰 판정·보고서 종합은 지금처럼 Claude가 한다.
- **사양 [같은 날 정정]**: 처음엔 M5 Pro 64GB를 권했으나 **`local_migration.md` §5b(8/29, 우리 부하 실측)와 충돌하는 과잉 권고였다.** 로컬 모델의 일이 요약·분류뿐이면 8~14B급이면 되고 24~32GB로 돈다 → **M6 베이스 + 램 여유(24GB↑, 32GB 옵션 있으면 그것)**. 한국어는 Qwen3 계열 또는 LG EXAONE, 런타임은 Ollama(MLX). 상세 = local_migration §5b-2.
- **이전 작업**: 윈도우 전용 부분(PowerShell 런처 `run_routine.ps1`, 작업 스케줄러, `kst_now` 윈도우 우회)을 macOS(launchd·bash)로 옮겨야 한다. 파이썬 스크립트는 대부분 그대로 돈다.
